# 突尼斯旅行展示网页

使用 HTML、CSS、JavaScript、Bootstrap 与 jQuery 组织的静态旅行内容展示项目。`R` 是仓库名称，不表示使用 R 语言。

## 页面与结构

- `index.html`：旅行主题首页。
- `web/hotel.html`、`attraction.html`、`route.html`、`food.html`：住宿、景点、路线及美食内容。
- `css/`、`js/`、`images/`：样式、脚本及素材。

## 本地预览

在仓库根目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8000/ 。仅预览静态页面，无数据库和服务端 API。

## 展示边界
